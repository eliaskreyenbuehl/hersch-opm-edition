Impressum

Dies ist ein Abklatsch der richtigen «Edition Jeanne Hersch», publiziert von der Zentralbibliothek Zürich unter folgender Adresse: https://edition-jeanne-hersch.org/

Der Prototyp, der auf diesen GitHub Pages publiziert wurde, wird bald wieder gelöscht und dient ausschliesslich zum Testen alternativer Technologien zur Erstellung von Editionsfrontends. Dieser Prototyp wurde mithilfe des Open Processing Models (OPM) https://opm.e-editiones.org/ und Claude Code erstellt.
