Impressum

Dies ist ein Abklatsch der richtigen «Edition Jeanne Hersch», publiziert von der Zentralbibliothek Zürich unter folgender Adresse: https://edition-jeanne-hersch.org/

Der Prototyp, der auf diesen GitHub Pages publiziert wurde, wird bald wieder gelöscht und dient ausschliesslich zum Testen alternativer Technologien zur Erstellung von Editionsfrontends. Dieser Prototyp wurde mithilfe des TEI Processing Models https://opm.e-editiones.org/ und Claude Code erstellt.

Datenschutz

Diese Website setzt keine Cookies und verwendet kein Tracking und keine Webanalyse. Schriften, Skripte und Bilder werden vom selben Server geladen wie die Seiten, es werden keine Inhalte von Drittanbietern eingebunden.

Die Website liegt bei GitHub Pages. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse.
